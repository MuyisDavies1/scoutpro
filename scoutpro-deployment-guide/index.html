Deploy with Nginx on Ubuntu Server
20 min

PWA
📲 Make It Installable (PWA)
A Progressive Web App lets users install ScoutPro directly from their browser — no App Store needed. Works on iOS and Android.
What is a PWA? Users visit your website, tap "Add to Home Screen", and ScoutPro appears as an app icon on their phone — with offline support and a splash screen.
1
Create the Web App Manifest (manifest.json)
Required

Create a file called manifest.json in your football-scouting-app folder:

json – manifest.json
{
  "name": "ScoutPro – Football Scouting",
  "short_name": "ScoutPro",
  "description": "FIFA-Licensed Football Scouting Platform",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#060e1a",
  "theme_color": "#0f4c81",
  "orientation": "portrait",
  "icons": [
    { "src": "icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "icon-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any maskable" }
  ]
}
2
Create the Service Worker (sw.js)
Required

Create sw.js in the same folder — this enables offline support:

javascript – sw.js
const CACHE = 'scoutpro-v1';
const ASSETS = ['/', '/index.html', '/app.js', '/data.js', '/manifest.json'];

self.addEventListener('install', e => {
  e.waitUntil(caches.open(CACHE).then(c => c.addAll(ASSETS)));
});

self.addEventListener('fetch', e => {
  e.respondWith(
    caches.match(e.request).then(r => r || fetch(e.request))
  );
});
3
Link Manifest & Register Service Worker in index.html
Required

Add these two snippets to your index.html:

html – inside <head>
<!-- Add to <head> -->
<link rel="manifest" href="/manifest.json"/>
<meta name="apple-mobile-web-app-capable" content="yes"/>
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent"/>
<meta name="theme-color" content="#0f4c81"/>
html – before </body>
<!-- Add before </body> -->
<script>
  if ('serviceWorker' in navigator) {
    navigator.serviceWorker.register('/sw.js')
      .then(() => console.log('SW registered'));
  }
</script>
After deploying, users on mobile can tap "Add to Home Screen" in their browser menu to install ScoutPro as an app!

Android App
Prerequisites: Node.js (v16+), npm, Git. For iOS: macOS + Xcode. For Android: Android Studio (Windows/Mac/Linux).
1
Install Node.js & Capacitor CLI
One-time setup
bash
# Install Node.js from https://nodejs.org (choose LTS version)
# Verify installation:
node --version   # Should show v18.x or higher
npm --version    # Should show 9.x or higher

# Install Capacitor CLI globally
npm install -g @capacitor/cli

# Verify Capacitor
npx cap --version
2
Initialize Capacitor in the ScoutPro Project
5 min
bash
# Navigate to your ScoutPro folder
cd football-scouting-app

# Initialize a package.json (if not exists)
npm init -y

# Install Capacitor core and CLI locally
npm install @capacitor/core @capacitor/cli

# Initialize Capacitor (answer the prompts)
npx cap init
#   App name: ScoutPro
#   App ID:   com.scoutpro.app  (reverse domain format)
#   Web dir:  ./  (current folder, since index.html is here)
The App ID (e.g., com.scoutpro.app) must be unique. Use your own domain in reverse, e.g., com.yourname.scoutpro
3
Add iOS and Android Platforms
2 min
bash
# Install iOS and Android platform packages
npm install @capacitor/ios @capacitor/android

# Add iOS platform (creates ios/ folder)
npx cap add ios

# Add Android platform (creates android/ folder)
npx cap add android

# Sync your web files into native projects
npx cap sync

# Your folder structure now looks like:
# football-scouting-app/
#   ├── index.html
#   ├── app.js
#   ├── data.js
#   ├── ios/          ← Xcode project
#   ├── android/      ← Android Studio project
#   └── capacitor.config.json
iOS requirement: You MUST have a Mac with Xcode installed. You also need an Apple Developer account ($99/year) to submit to the App Store.

10 min

Build & Archive for App Store
$99/yr Apple Dev Account
Select "Any iOS Device" as the build target
In the top toolbar, change the device from a simulator to "Any iOS Device (arm64)"
Archive the build
Menu: Product → Archive. Wait for the build to complete (~2-5 min)
Distribute via App Store Connect
In the Organizer window: click "Distribute App" → "App Store Connect" → Upload
Submit on App Store Connect
Visit appstoreconnect.apple.com → Create new app → Fill in metadata → Submit for Review
Wait for Apple Review
Apple reviews apps within 1–3 business days. You'll get an email when approved.
Apple Developer Program costs $99/year. Register at developer.apple.com/programs
Android works on Windows, Mac, and Linux. Google Play registration is a one-time fee of $25.
1
Install Android Studio & Open Project
Free
bash
# 1. Download Android Studio from: https://developer.android.com/studio
# 2. Install Android SDK (Android Studio will prompt you)
# 3. Set ANDROID_HOME environment variable:

# On Mac/Linux (.bashrc or .zshrc):
export ANDROID_HOME=$HOME/Library/Android/sdk
export PATH=$PATH:$ANDROID_HOME/tools:$ANDROID_HOME/platform-tools

# On Windows (System Environment Variables):
# ANDROID_HOME = C:\Users\YourName\AppData\Local\Android\Sdk

# 4. Sync and open in Android Studio
npx cap sync android
npx cap open android
2
Configure App in Android Studio
10 min
Open build.gradle (app level)
In Android Studio: app → build.gradle. Set applicationId "com.yourname.scoutpro"
Set App Name
Edit app/src/main/res/values/strings.xml: <string name="app_name">ScoutPro</string>
Add App Icon
Right-click res folder → New → Image Asset. Upload your 1024×1024 ScoutPro icon.
Set Version
In build.gradle: versionCode 1, versionName "1.0.0"
3
Generate Signed APK / AAB for Google Play
$25 one-time
Generate a Keystore (signing key)
In Android Studio: Build → Generate Signed Bundle/APK → Create new keystore → Save it safely!
Select Android App Bundle (AAB)
Choose Android App Bundle (.aab) — Google Play requires this format. Select Release build type.
Build the AAB file
Click Finish. The .aab file will be in app/release/app-release.aab
Register on Google Play Console
Visit play.google.com/console → Pay $25 → Create app → Upload the .aab file
Fill in Store Listing
Add screenshots, description, category (Sports), content rating → Submit for review
Google Review & Publish
Google reviews within 3–7 days for new apps. Updates are usually approved within hours.
CRITICAL: Never lose your keystore file or password. You cannot update your app on Google Play without it!
4
Build via Command Line (Alternative)
Advanced
bash
# Build release APK via Gradle (inside android/ folder)
cd android
./gradlew assembleRelease   # Mac/Linux
gradlew.bat assembleRelease  # Windows

# Output: android/app/build/outputs/apk/release/app-release-unsigned.apk

# Sign the APK
jarsigner -verbose -sigalg SHA1withRSA -digestalg SHA1 \
  -keystore my-release-key.keystore \
  app-release-unsigned.apk alias_name

# Align the APK
zipalign -v 4 app-release-unsigned.apk ScoutPro.apk

# Build AAB (recommended for Play Store)
./gradlew bundleRelease

🏪 What You Need for the Stores
Prepare these assets before submitting to the App Store or Google Play.
Apple App Store
$99/year

$25 once

  • Short Description (80 chars)
  • Full Description (4000 chars)
  • Privacy Policy URL (required)
  • Content Rating questionnaire
  • Category: Sports
